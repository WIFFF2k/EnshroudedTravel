# 灵火神殿传送助手

目标：单人游戏中，使用原生地图点击已发现的灵火神殿传送；提供中文桌面开关和游戏连接状态

## 当前环境

- 游戏目录：`C:/Games/Enshrouded`
- Steam Build ID：`25988036`
- 存档目录：`C:/Steam/userdata/LOCAL_ACCOUNT/1203620`
- 首次备份：`backups/20261019-173417/1203620`
- 备份校验：35 个文件与来源逐一 SHA-256 相等，备份时游戏已退出
- 上游工具：EML v0.2.0，源代码固定到 `16708594d686b030d909f2d835b199d879ea9ad8`

## 安全边界

1. 存档只读取和复制，不做格式改写，不自动覆盖或恢复正式存档
2. 先在 `lab/game` 的独立游戏资源副本验证补丁，不对原始资源建立可写硬链接
3. 启用和关闭之前检查游戏是否运行，运行期间禁止改资源
4. 关闭时仅恢复本工具持有且通过校验的资源；出现第三方修改或游戏更新时停止操作
5. 未完成原生地图和落点实测前，不声称传送功能已通过验收

## 模块

- `src`：桌面界面、进程状态、备份和资源切换
- `mod`：单一用途的地图传送补丁
- `tools`：固定版本且经过发布摘要校验的 EML
- `lab`：资源分析和验证，不使用正式存档进行行为测试
- `backups`：独立备份与校验清单
- `reports`：真实命令结果和测试记录

## 当前验证状态

已编译桌面助手，已通过资源副本补丁、运行中保护和界面连接状态测试；未完成游戏内传送验收

## 打开方式

运行本目录的 `EnshroudedTravel.exe`，保留旁边的 `payload` 目录

目前属于待实机验收版本，不建议在主角色和主世界中启用

- 自动显示游戏进程是否已识别，进程连接不等于传送落点已经验证
- 游戏运行时禁用启用、恢复和备份按钮；不会强制结束游戏
- 游戏退出后，启用前复制当前 Steam 存档并逐文件核验
- 启用只修改两个游戏资源文件，不写角色和世界存档
- 关闭时恢复经过 SHA-256 核验的原版游戏资源
- 游戏更新、第三方修改、资源未知时拒绝操作，不覆盖未知内容
- 需要正常退出游戏后切换，再重新启动；当前不是运行中热开关
