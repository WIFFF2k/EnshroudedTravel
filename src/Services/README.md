# 运行时服务

主界面通过 RuntimeTravelService 的各功能分文件访问游戏进程，TravelService 负责版本核验和存档备份

地图缩放逐份校验缓存与扫描结果，地址被游戏复用后排除失效副本，保留完整匹配的有效配置
同进程轮询持续刷新缩放就绪状态；第五档未知值、副本状态不一致和指令不匹配仍明确报错
所有副本都失效时停止写入，提示打开地图后重新连接；仅在完整复核成功后保存扫描地址

昼夜功能位于 RuntimeTravelService.DayNight.cs，只沿 Build 26082781 已核实的模块指针链读取当前世界，不参与传送和缩放的冷扫描
每次操作重新核对对象身份、世界加载状态和时间配置，只写时间偏移与更新序号，等待游戏自身输出目标时段后报告成功
白天和黑夜属于一次性调整，关闭助手不回退时间，不加入启用全部
伤害提升位于 RuntimeTravelService.DamageBoost.cs，在命中结算处放大玩家造成的负生命变化量，治疗不变，仅适用本地单人世界
伤害调用点为 `0x3D6D53`，原函数为 `0x3DEFF0`；原始施法者阵营必须为 7，目标玩家阵营 7、8 排除，按 x64 调用约定返回并保留额外使用的寄存器
阵营依据为类型表 FactionType 和 HasFaction 原生节点；上下文 +160h 为阵营组件表，ApplyDamage 栈帧 +1A0h 为原始施法者，+140h 为目标阵营组件
代码页搜索、分配和校验在暂停线程之前完成，同一服务连接内复用；暂停范围只包含调用字节切换、回读和失败恢复，每次写入均刷新指令缓存
关闭时恢复原调用，保留已接入过的存根供在途线程返回，游戏退出时由系统释放；重新打开助手再次启用会增加一个 4 KB 提交页，不扫描旧存根，不加入启用全部
日志记录切换耗时及命中结算原值 → 放大值；每秒读取 24 字节计数，不扫描战斗内存，实际扣血和关闭恢复仍待用户实战验收
字段依据及验收结果见 reports/daynight-verification.md
