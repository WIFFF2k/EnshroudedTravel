# 雾锁王国修改器

用于《雾锁王国》本地单人游戏，提供地图传送、更远地图视野、瘴气中传送、免费增大箱子、昼夜调整和十倍伤害功能，支持在游戏运行时开启与关闭

## 功能介绍

| 功能 | 使用效果 |
| --- | --- |
| 地图传送 | 通过游戏地图传送到支持的地点，包括灵火精华、宝石锻炉、已解锁远古尖塔、古代方尖碑、已发现的瘴气根、任务感叹号等 |
| 更小缩放 | 增加一档更远的地图视野，方便查看更大范围的地点 |
| 瘴气中传送 | 允许在瘴气区域使用快速传送，下落和水中的限制仍保留 |
| 免费增大箱子 | 普通箱和魔法箱的容量升级无需材料与等级要求，仍需逐级升级 |
| 白天 / 黑夜 | 将当前世界调整到对应时段，之后时间继续正常流动 |
| 伤害提升10倍 | 将玩家对非玩家目标造成的命中伤害放大十倍，包含魔棒等法术，治疗量不变 |
| 无限体力 | 跳过统一体力消耗结算，可能影响其他实体；未覆盖其他独立扣除路径 |
| 备份存档 | 在游戏完全退出后，将配置目录中的存档复制到独立备份文件夹 |

「启用全部」包含传送、更小缩放、瘴气中传送和免费增大箱子；白天、黑夜、十倍伤害和无限体力需要单独点击

地图传送不会揭露隐藏地点或提前解锁尖塔。免费增大箱子只影响容量升级，不包含箱子附魔、普通制作或容量上限提升

## 使用前准备

- 使用 64 位 Windows，并安装可运行该程序的 .NET Framework
- 当前适配游戏版本为 Steam Build **26430625**，其他版本会提示不支持
- 使用本地单人世界，首次使用前先备份存档，建议先在备用角色和世界中体验
- 从 GitHub 拉取仓库，或点击 Code → Download ZIP 并完整解压到可写入的文件夹

仓库根目录提供 `EnshroudedTravel.exe` 和 `config.example.json`。程序已包含运行所需资源，无需编译或另外下载文件

## 配置游戏与存档路径

1. 将 `config.example.json` 复制一份，重命名为 `config.local.json`
2. 用记事本打开 `config.local.json`，填写游戏目录和存档目录
3. 保存文件，双击同一文件夹中的 `EnshroudedTravel.exe`

配置示例：

```json
{
  "gameDirectory": "D:/Games/SteamLibrary/steamapps/common/Enshrouded",
  "saveDirectory": "C:/Program Files (x86)/Steam/userdata/你的账户目录编号/1203620"
}
```

以上路径仅为示例，请填写自己电脑上实际存在的目录

### 游戏目录

`gameDirectory` 填写安装《雾锁王国》的文件夹，打开该文件夹后应能直接看到 `enshrouded.exe`

填写文件夹的完整路径，不要包含末尾的 `enshrouded.exe` 文件名

### 存档目录

`saveDirectory` 填写需要备份的存档文件夹。使用 Steam 云存档时，检查 Steam 安装目录下的 `userdata`，找到当前账户对应的目录，再进入 `1203620`

如果这里有 `remote` 文件夹，请填写其上一级 `1203620` 目录。若你的存档实际保存在其他位置，填写实际存档目录

存在多个账户目录时，先确认哪一份包含自己的角色与世界存档；修改器会备份你填写的整个文件夹，不会自动识别账户

### 填写注意事项

- 两个目录都必须填写，且必须是完整路径
- 路径建议使用 `/`；使用反斜杠时，在 JSON 中写成 `\\`
- 保留英文双引号和两个字段之间的逗号，最后一项末尾不要加逗号
- 确认文件名是 `config.local.json`，而不是 `config.local.json.txt`
- 调整路径后，正常关闭并重新打开修改器

## 开始使用

1. 启动修改器，确认界面显示的游戏目录和存档目录正确
2. 首次使用时，保持游戏关闭，点击「备份存档」并等待成功提示
3. 启动游戏，进入本地单人世界
4. 等待修改器完成连接和定位，对应按钮可用后再操作
5. 点击需要的功能；想同时开启四项常用功能，可以点击「启用全部」

显示游戏进程编号表示已发现游戏，功能是否可用以按钮和状态提示为准。定位期间可以点击「取消定位」，之后程序会重新检查连接

### 传送与地图缩放

开启传送后，重新打开游戏地图，选择支持的地点使用传送。关闭传送后，重新打开地图即可恢复原有行为

点击「开启更小缩放」后，重新打开地图并继续缩小。开启后的缩放档位为 `16 / 8 / 4 / 2 / 0.45`；关闭后恢复原生四档

### 箱子、昼夜与伤害

开启「免费增大箱子」后，在游戏中打开箱子，点击「增大」逐级升级。关闭功能只恢复升级条件，已经获得的箱子容量不会缩回

「白天」和「黑夜」各执行一次时间调整，不锁定时间；关闭修改器后也不会回到调整前的时刻

「伤害提升10倍」需要单独开启，再次点击可关闭。下方记录区域会显示实际触发的伤害数值；只有开启提示时，仍需攻击目标后确认触发记录

「无限体力」位于手动调整区第二行，开启后不再扣除统一体力消耗，关闭后恢复原指令；不会立即补满体力，正常关闭修改器也会恢复该开关。该结算点可能影响其他实体，仅用于本地单人世界；冲刺、滑翔及其他动作的实际覆盖范围仍待游戏内验收

## 备份与退出

备份前先正常退出游戏，等待游戏完全关闭，再点击「备份存档」。备份完成后，界面会显示保存位置

每次备份会存放到修改器目录下 `backups` 中单独的时间命名文件夹，保留之前的备份

切换角色或世界前，先关闭已开启的功能。正常关闭修改器时，会恢复本次由它开启的功能开关；已完成的昼夜调整、箱子升级和游戏进度仍然保留

如果关闭时提示恢复失败，请保留窗口，查看记录并重试关闭

## 常见问题

| 提示或现象 | 处理方式 |
| --- | --- |
| 配置未完成、缺少配置文件 | 检查程序旁是否有 `config.local.json`，确认两个目录都已填写 |
| 配置格式错误 | 对照示例检查英文双引号、逗号和路径中的斜杠 |
| 找不到游戏文件 | 将游戏目录设为直接包含 `enshrouded.exe` 的文件夹 |
| 存档目录不存在 | 打开填写的目录，确认账户目录编号和盘符正确 |
| 当前游戏版本尚未适配 | 使用与游戏版本匹配的修改器，等待对应版本支持 |
| 程序文件不完整或内置资源校验失败 | 重新获取仓库根目录的 `EnshroudedTravel.exe`，确保下载完整 |
| 一直等待游戏或尚未找到传送数据 | 确认运行的是配置目录中的游戏，进入世界后等待；仍未就绪时重新打开修改器 |
| 更小缩放尚未就绪 | 进入世界并打开一次游戏地图，再正常关闭并重新打开修改器 |
| 昼夜或伤害功能不可用 | 确认已进入本地单人世界，并等待世界加载完成 |
| 无法备份存档 | 完全退出游戏后重试，并检查存档目录是否正确 |
| 再次启动没有出现新窗口 | 修改器只运行一个窗口，重复启动会显示已有窗口 |

其他问题可查看窗口下方的记录。反馈时提供游戏版本、操作步骤和错误提示；分享截图前遮住个人存档路径
